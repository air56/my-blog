计算机网络入门

这是一篇根据一次网络基础学习对话整理的入门笔记。为了方便理解，把网络想象成一座城市：IP 是地址，网关是出口，端口是房间号，DNS 是电话簿。

第一次提问：IP、网关、端口与网络安全

IP 地址：设备在网络中的地址

IP 地址就像网络世界的门牌号。比如 192.168.10.104，表示一台设备在局域网中的位置。

常见的内网 IP 包括：

  • 192.168.x.x
  • 10.x.x.x
  • 172.16.x.x 到 172.31.x.x

内网 IP 主要在家庭、学校或公司内部使用。家里的电脑和手机通常使用内网 IP，路由器再代表它们访问互联网，这个过程叫 NAT（网络地址转换）。

子网掩码：判断是不是同一个“小区”

例如：

IP 地址：192.168.10.104
子网掩码：255.255.255.0

这通常表示 192.168.10.xxx 属于同一个局域网。192.168.10.104 和 192.168.10.105 往往可以直接通信，而访问其他网络时需要经过路由器。

网关：通往外部网络的出口

如果电脑是 192.168.10.104，默认网关是 192.168.10.1，那么 192.168.10.1 通常就是路由器的局域网地址。

电脑 192.168.10.104
        │
        ▼
路由器 192.168.10.1
        │
        ▼
互联网

同一局域网里的设备像邻居，可以直接找到彼此；要访问互联网，就必须从网关这个“小区大门”出去。

端口：找到设备里的具体服务

IP 只能找到一台设备，但一台电脑可以同时运行浏览器、游戏、文件共享和远程桌面，所以还需要端口号。

192.168.10.104:8080

这里 192.168.10.104 是设备地址，8080 是服务的“房间号”。常见端口有：

端口 常见用途
80 HTTP 网页
443 HTTPS 加密网页
53 DNS 查询
22 SSH 远程管理
3389 Windows 远程桌面

端口转发相当于把小区的一扇门直接指向家里某个房间，因此不懂用途时不要随便开放端口。

DNS：把域名翻译成 IP

人容易记住 www.example.com，电脑更需要服务器的 IP 地址。DNS 就像互联网的电话簿：

www.example.com
        │
        ▼
DNS 查询域名对应的 IP
        │
        ▼
浏览器连接服务器

路由器和网络安全

家用路由器通常同时承担 Wi-Fi、DHCP、网关、NAT 和防火墙等工作。DHCP 会自动给设备分配 IP、子网掩码、网关和 DNS。

网络安全可以用“房屋安全”理解：密码是钥匙，防火墙是门卫，HTTPS 是密封的信封，系统更新是在修补门锁漏洞。

最重要的习惯是：使用 WPA2 或 WPA3、设置强密码、为重要账号开启双因素认证、及时更新设备，不随便打开陌生链接，也不要在不清楚用途时开启端口转发。

第二次提问：ping 1.1.1.1 在做什么

ping 1.1.1.1

这条命令会向公网中的 1.1.1.1 发送一个很小的测试请求，等待对方回应，用来检查电脑能否经过路由器到达互联网中的某个公网地址。

1.1.1.1 是 Cloudflare 提供的公网地址，也常被用作 DNS 服务地址。但在 ping 命令中，它只是一个测试目标，并不是在进行 DNS 查询。

常见返回结果中的：

  • 时间=35ms：一次来回大约需要 35 毫秒，数值越小通常越快；
  • 0% 丢失：测试数据包全部收到回复；
  • 请求超时：可能是网络不通，也可能是对方禁止 ICMP ping，不能只凭这一项断定网页一定打不开。

可以先测试本地网关，再测试公网：

ping 192.168.10.1
ping 1.1.1.1

第一个主要检查电脑到路由器，第二个主要检查路由器之外的网络。

第三次提问：nslookup 与 DNS 地址

nslookup example.com

这个命令是询问 DNS：“example.com 对应哪些 IP 地址？”输出中的：

Server:  192.168.1.1
Address: 192.168.1.1

表示本次查询使用的 DNS 服务器是 192.168.1.1。它不一定就是默认网关，可能来自路由器、网络软件、VPN 或手动配置。

Name:    example.com
Addresses: 2606:4700:10::6814:179a
           2606:4700:10::ac42:93f3
           172.66.147.243
           104.20.23.154

这里的 Addresses 是域名对应的服务器地址。带冒号、较长的地址是 IPv6；四段数字组成的地址是 IPv4。一个域名有多个地址，可以用于分担访问压力、提高可靠性，并同时支持 IPv4 和 IPv6。

Non-authoritative answer 表示 192.168.1.1 不是 example.com 的官方权威 DNS，只是替你查询或从缓存中返回结果，这通常是正常现象。

example.com 是专门保留给教程和文档使用的示例域名，不是专门的 DNS 测试网站，但很适合用来测试 DNS 是否能够解析域名。

第四次提问：MAC 地址与 Wi-Fi 配置

MAC 地址：网卡的硬件身份证

MAC 地址通常长这样：

AA:BB:CC:11:22:33

它是网卡在局域网中的硬件标识。可以这样区分：

MAC 地址 = 网卡的身份证
IP 地址  = 设备当前在网络中的住址

设备换到另一个 Wi-Fi 后，IP 地址通常会改变；MAC 地址通常保持不变，但 Windows 可以使用随机硬件地址来保护隐私。

随机硬件地址：给不同 Wi-Fi 使用不同的临时 MAC

开启后，电脑连接不同 Wi-Fi 时，可以使用不同的随机 MAC 地址，减少公共 Wi-Fi 通过 MAC 地址长期识别和追踪同一台设备的可能性。

普通家庭、学校和咖啡店 Wi-Fi 通常建议开启。但如果网络使用 MAC 白名单、固定 IP、设备限速或特殊认证，随机 MAC 变化后可能被当成新设备，需要重新配置。

IP 分配：自动（DHCP）

Wi-Fi 设置中的“IP 分配：自动（DHCP）”表示由路由器自动提供：

IP 地址
子网掩码
默认网关
DNS 服务器

普通家庭用户建议保持自动。只有搭建服务器、配置打印机、做虚拟机实验或网络明确要求固定地址时，才考虑手动设置 IP。

DNS 服务器分配：自动（DHCP）

“DNS 服务器分配：自动（DHCP）”表示由路由器告诉电脑使用哪个 DNS。手动填写 DNS 可以用于排查 DNS 故障或使用指定的 DNS 服务，但更换 DNS 不会直接让所有网络速度变快。

最后可以用四句话记住本篇内容：

IP 地址   = 找到哪一台设备
端口      = 找到设备里的哪一个服务
网关      = 通往外部网络的出口
DNS       = 把域名翻译成 IP
MAC 地址  = 网卡的硬件身份证
