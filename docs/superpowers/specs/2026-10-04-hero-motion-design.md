# 首页图片粒子与动态效果

用户确认采用柔和光点漂浮、轻微鼠标视差和背景缓慢呼吸的组合。

- 保留海边插画、首页文字与文章列表。粒子使用白色、浅蓝和少量暖金色，衬托原图；不增加额外展示卡片。
- 新建独立客户端装饰组件 `HeroScene`，由首页服务端组件调用，图片地址与现有 `HeroLoader` 一致。
- Canvas 绘制有限数量的粒子，桌面 42 个、手机 18 个，刷新限制为约 30 FPS，像素比例上限为 2。
- 图片缓慢缩放，鼠标通过平滑插值产生最多 8px 的视差。触摸设备不跟随鼠标。
- 装饰层不拦截指针，不进入辅助技术阅读顺序。右侧粒子减弱，保护文字可读性。
- 首屏离开视野、标签页隐藏时停止 Canvas 循环并暂停 CSS 动画；重新进入时恢复。
- 系统设置减少动态效果时关闭粒子、视差与呼吸，保留静态原图。无 JS 时仍能阅读首页。
- 验证覆盖真实浏览器的粒子绘制、鼠标反馈、暂停恢复、减少动态效果、手机与无 JS；另外运行现有测试、lint 和生产构建。
