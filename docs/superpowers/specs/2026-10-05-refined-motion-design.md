# 柔和景深动效预览

用户要求先生成浏览器预览，确认后才推送；已选择「柔和景深：细腻、有层次」。本次基于实际网站源码 master 的 9fb3f93，在 codex/refined-motion-preview 本地分支实施。

## 体验

- 保留黑黄视觉、首页背景、文章和布局。
- 页面正文使用约 420ms 的淡入、12px 位移、3px 景深模糊；页头稳定。移除原有固定时长的黑屏假加载，不等待动画才导航。
- 导航底部一条细线随当前栏目滑动，子分类属于「分类」，手机仍能完整使用导航。
- 日夜按钮切换深色与暖白阅读主题，支持时从按钮中心展开约 460ms 的圆形揭示；不支持相关 API 时即时切换。选择记忆在本机。
- 文章和分类卡片只抬升 3px，保持克制。
- 开启系统减少动态效果时不执行位移、模糊和主题揭示。无 JavaScript 时正文保持可读。

## 实现边界

原生 React、CSS 和 Web Animations API，不增加生产依赖。路由仍由 Next Link 管理，保留前进后退、修改键、新标签页和锚点语义。失败、取消与连续操作不留下遮挡。

## 验收

真实浏览器检查导航、返回、主题持久化、主题 API 降级、减少动态效果、手机宽度和无 JS；执行现有 Markdown 与首页动效回归，lint 与静态导出构建。保留运行中的本地预览，等待用户确认，不推送。
